Threat Detector is a Master’s thesis project at the University of Passau that explores the feasibility of live interception of outbound internet packets generated by 
Android applications installed on a user’s device. This is achieved with the support of an intercepting VPN/packet-capture application called PCAPdroid.

The application operates by receiving network traffic information from PCAPdroid in PCAPNG format via a local TCP server. The captured data includes:
- The public IP address to which the internal application is transmitting data.
- The application package name from which the outbound traffic originates.

Using the outbound IP address of each corresponding app, Threat Detector queries AbuseIPDB, a platform that provides IP reputation intelligence. The response includes a score indicating
the likelihood that the IP address is malicious, along with details such as the country of origin and reasons for negative reports. These results are then presented to the user for each 
internet-connected application.
